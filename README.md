# Math Analyze｜國中數學自適應刷題系統

五至六週的八年級數學段考刷題與測驗分析，主要改善 **速度、非知識性失分、知識守備覆蓋**。

## 啟用

1. 打開 [GitHub Pages](https://github.com/kaoelvmpvm/Math_analyze/settings/pages)，Source 選 GitHub Actions，網站部署流程會在推送後啟動。
2. 開啟網站，在「設定／匯入題庫」選擇教師持有的 `Math_analyze_780題原圖包_v4_PDF原版裁切.zip`（包含 `catalog.json` 與 `cards/*.webp`）。
3. 先建立學生代號，再產生測驗卷、印出試題、登記錯題，下一回測驗就會依紀錄分配考點。
4. 每次使用後按「下載備份」，保存測驗及學生資料。更換瀏覽器時，可匯入備份；題圖包須另外匯入。

## 資料與限制

- 本儲存庫只包含網頁程式，不包含受版權保護的780題題圖、不包含學生個人資料。
- 題圖包只在使用者的瀏覽器中解壓，題圖存入 IndexedDB，紀錄存入 localStorage；清除網站資料可能使紀錄遺失。
- 使用學生**座號或匿名代號**即可，不建議輸入完整姓名。
- 初版使用原題庫的答案與初篩考點分類。數學解答尚未全面獨立驗算；原有停用題、超綱疑義題及待人工覆核題預設不參與自動抽題。
- 系統只蒐集每回**總作答時間**，不能推定每題的真實解題秒數；未經確認的錯因不會自動判定成粗心。
- 預設出卷使用已完成初篩的題目；如欲調整單題分類/停用狀態，可在題庫介面操作覆核。

## 核心流程

題庫匯入 → 建立學生 → 生成短回合/45分鐘試卷 → 列印 → 點選錯題/未作答 → 填寫總耗時 → 查看考點分析 → 生成下一回試卷。

## 技術

Vanilla JavaScript + IndexedDB + localStorage；僅載入 JSZip 用於教師本機 ZIP 解壓，無伺服器/API/AI費用。

## 題圖裁切修復（2026-10-16）

第一版直接依原PDF文字基線切割，造成高於基線的根號、分式上緣被截斷。現改為將來源Word中的每道題獨立排版並完整輸出後才裁切，重新生成780張WebP。題包的 `metadata.asset_version` 為 `v2-isolated-layout`；舊版題包會被網站拒絕，以避免誤用殘缺題目。重新匯入題包保留學生、考卷及錯題資料，並自動更新瀏覽器圖片快取。

## v3 修復（2026-10-16）

因原始Word有大量 Equation.3/MathType 舊式 OLE 公式，即使逐題切頁，非Windows轉檔引擎仍可能將數字壓縮重疊。v3 改為先將內嵌 WMF/EMF 公式預覽轉成靜態 PNG，移除 OLE 物件，最後才逐題生成 WebP。

- v3 識別碼：`v3-rasterized-ole`；舊 v1/v2 ZIP 不再接受。
- 無法安全轉換的公式會標記為 `render_integrity=needs_manual_review`，自動出卷一律排除，不能透過「教師核准」覆蓋。
- 已有考卷與學生紀錄保留，但應重新匯入 v3 ZIP 才能重新預覽或列印。
- 題庫數學答案的獨立驗算與全部題圖的人工目視確認仍未完成，請勿將候選可用視作正式命題驗收。

## v4｜以教師親自匯出的原版 PDF 切題（2026-10-16）

- 啟用題包版本：`v4-native-pdf-crops`，不再由非 Windows 程式解析舊式 MathType/OLE 公式。
- 題目來源：教師提供的三份原始題庫 PDF（22、23、13頁，共780題），直接渲染、依題號裁切；44題合併跨頁內容。來源正確答案標記已遮蔽。
- 780張題圖可正常解碼，經結構與像素檢驗；此處的驗收**不是780題答案逐題數學驗算**。
- **732題暫列出卷候選，48題停用或待審**（33題考點分類、9題超範圍疑義、2題重複、3題來源PDF缺選項、1題因式定義疑義）。
- 三題來源PDF不完整，強制停用：`01-105`、`01-162`、`02-184`。
- `01-011`已覆核唯一答案C，撤銷先前錯誤停用；`03-007`保留教師確認。
- ZIP必須由教師在網站端手動匯入，**不要直接提交到公開 GitHub Repo**；匯入新版不會刪除學生或既有錯題記錄。
